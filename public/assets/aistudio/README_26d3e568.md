# Совпадение — помощник SiXeS

Локальное браузерное приложение без сборки и сторонних библиотек. Показывает оригинальные задания, управляет шестью раундами и минутным таймером, фиксирует счёт и автоматически сохраняет текущую партию в `localStorage`.

## Запуск

Для PWA и Service Worker откройте папку через локальный HTTP-сервер (Service Worker не работает при открытии `index.html` через `file://`). Например, из этой папки:

```sh
python3 -m http.server 8000
```

Затем откройте `http://localhost:8000`. После первой загрузки основные ресурсы приложения доступны офлайн; браузер предложит установить приложение, если поддерживает установку PWA.

## Правила и источники

Шесть раундов идут в порядке Совы, Жаворонки, Блиц, затем повторяются. На ответы отводится одна минута. За совпавший ответ в раундах Совы/Блиц и за уникальный ответ в Жаворонках начисляется очко; выполнение условия всеми шестью ответами даёт бонусное очко. Строгость совпадений выбирается перед партией. Подробности встроены в экран «Правила».

Правила сверены по русскому изданию SiXeS / «Совпадение», версия 1.0: [PDF правил Hobby Games](https://hobbygames.kz/download/rules/SovPadenie_rules.pdf) и [описание правил Hobby Games](https://hobbygames.ru/sovpadenie/rules).

Названия заданий и категории добавлены из предоставленного пользователем PDF. Приложение использует только текст заданий, без иллюстраций и оформления карточек. В каждой из трёх колод — 72 задания/карты из файла.

## Язык интерфейса

Кнопка `EN` / `RU` в верхней панели мгновенно переключает интерфейс, правила и задания всех колод; выбор языка сохраняется на устройстве. Английские переводы карточек включены в приложение и работают офлайн.
